`study-20261021T202311Z.tar.gz` contains three I-IV campaigns, three
precision repetitions, six sustained-power windows, nine GEMM profiles and
the analysis products. The acquisition source is
`5f6902c536a2d35183d2d2cbe0ec2561364f4884`.

SHA-256:

```
8d410c2230ffad11be094df427c53394ed6145782d7a5890b6378c649a81254f
```

The archive is 3,682,986 bytes with 171 members. Its log matches
`study-20261021T202311Z.log` in this directory. Nine CSV and seven SVG
analysis products were independently regenerated byte-for-byte.
`results/metadata.json` preserves the acquisition/analysis identity; new
regenerations record their own paths and timestamps.

From this directory, run:

```bash
sha256sum -c study-20261021T202311Z.tar.gz.sha256
```
